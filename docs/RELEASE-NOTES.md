## CADinvent portable

Download the package for your operating system, extract it, and start the executable. The app opens in your existing browser. No Electron, bundled browser, Node.js, Python, installation, or account is required.

Most Windows PCs should use **cadinvent-windows-amd64.zip**. Apple Silicon Macs should use **cadinvent-darwin-arm64.tar.gz**. Other architecture packages are provided as well. Choose a portable asset, not the automatically generated source-code archives.

Includes batch STL/OBJ/PLY import, independent personal workspaces, category shelves, search, part/category favorites, and 3D inspection. Export Workspace downloads one ZIP with root workspace.json and models/. Import Workspace restores it as a new project. The ± category button controls inclusion in All Parts; Unclassified starts excluded and is deletable. Workspace deletion requires confirmation and cleans up its browser-local files. Category deletion preserves its models.

Folder import, sample-library creation, and standalone JSON/CSV exports have been removed. Add models and model drag-and-drop remain available. Existing saved sample parts can still be opened/exported. All files stay in browser-local storage; keep workspace ZIP backups.

Read the included START-HERE.md for launch instructions, browser storage behavior, updates, and the current unsigned-package limitations. Checksums are in SHA256SUMS.txt.
